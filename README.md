## Current state

There is no application source or dependency manifest in this repository yet. This page records the project direction without implying that resume analysis, job matching, interview practice, or other features already work.

## Suggested first milestone

- Define one user task and the data it needs.
- Add a minimal, runnable application and a documented local setup.
- Keep resume and job-search data private; make external data sharing explicit.
- Add synthetic examples, an evaluation set, and clear limitations before describing model quality.
- Provide a demo only after the end-to-end workflow is verified.

## Privacy and responsible use

Career documents can contain contact details, employment history, and other personal information. Do not commit real resumes or API credentials. If an external model or job-search service is added, document what data leaves the device and why.
